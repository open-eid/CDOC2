    20. API Reference for shares server¶

    CDOC2 API References are available at the Open Electronic Identity GitHub CDOC2 Openapi repo

    Shares Server Openapi spec

    20.1 API usage samples¶

    20.1.1 Add Key Share¶

    Request:

    POST /key-shares
Content-Type: application/json
x-expiry-time: 2026-08-10T00:00:00Z

{
  "share": "c2FtcGxlLWtleS1zaGFyZS1kYXRhLWJhc2U2NC1lbmNvZGVkLXBheWxvYWQ=",
  "recipient": "etsi/PNOEE-48010010101"
}

    Response:

    HTTP/1.1 201 Created
Location: /key-shares/9a7c3717d21f5cf19d18fa4fa5adee21
x-expiry-time: 2026-08-10T00:00:00Z
x-expiry-time-adjusted: true
